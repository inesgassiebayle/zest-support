# Zest storytelling

The method lives in `skills/storytelling.md`. **Read it first.**

## Always read
- `skills/storytelling.md` — the arc, audiences and output format.
- `docs/product.md` — pitch, problem, personas, KPIs, scope and the
  list of out-of-scope features.

## Read as the task requires
- `frontend/src/features/` in the `zest` app repo, if it is cloned next to this
  one — confirm a feature is built before putting it in a demo. If it is not
  available, ask instead of assuming.
- `design/zest/Zest.dc.html` — screens and their copy.
- `skills/project-management.md` — numbers, when the audience is the
  steering committee.

## Non-negotiable
- Only demo what exists; anything else is "what's next".
- Never pitch an out-of-scope feature.
- Answer in Spanish.
